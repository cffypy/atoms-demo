# ⚛ Atoms Demo

> 对标 [atoms.dev](https://atoms.dev/) 的 **AI 智能体原型**：用自然语言驱动智能体生成**真实可交互**的单文件网页应用，并实时可视化预览。
> 纯静态、零后端、零构建 —— 一份 `index.html` 即可跑，天然适配 GitHub Pages。
>
> 🔗 **在线演示（公网可访问）**：https://cffypy.github.io/atoms-demo/
> 📦 **代码仓库**：https://github.com/cffypy/atoms-demo

## 这是什么

一个「自然语言 → 可交互网页」的 AI 智能体工作台。你在左侧描述想法，智能体会：

1. **需求分析 → 方案规划 → 代码生成 → 渲染预览**（带状态卡片与流式打字机效果）
2. 生成**完整、可运行的单文件 HTML 应用**，右侧 iframe 实时预览
3. 支持**多轮迭代**：把上一版代码作为上下文做增量修改（而非每次重生成）
4. 把生成的应用以**可视化网页形式**展示，并可一键导出 / 分享

## 核心特性

| 特性 | 说明 |
|:---|:---|
| 🤖 智能体驱动 | 意图识别 + 模板引擎 + 可选真实大模型，自动规划并生成应用 |
| 🖥 真实交互 | 生成的不是静态图，而是可点击、有状态的网页（待办/计算器/仪表盘/游戏…） |
| 🔁 多轮迭代 | 支持“改成深色模式”“把主题色换成红色”等增量编辑 |
| 💾 本地持久化 | 项目 / 对话 / 版本（V1、V2…）存入 localStorage，刷新不丢失 |
| 🔗 分享快照 | 把应用打包进 URL，任何人打开即可直接运行（无需服务器） |
| 🌐 默认在线 DeepSeek | 内置 Key 开箱即用，真实模型 SSE 流式生成；调用失败时自动回退离线引擎 |

## 快速开始

本项目是纯静态站点，**无需安装任何依赖**：

```bash
# 方式一：直接双击 index.html 在浏览器打开
# 方式二：本地起一个静态服务器（推荐，分享快照链接更稳）
cd atoms-demo
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

打开后即可在左侧输入需求开始生成。示例：

- “生成一个待办事项清单网页，支持添加、完成和删除”
- “做一个支持加减乘除的计算器”
- “生成一个 SaaS 产品落地页”
- “做一个数据可视化仪表盘”
- “把背景改成深色模式”（多轮迭代示例）

## 智能体（默认在线 DeepSeek）

应用**默认接入在线 DeepSeek 大模型**（`deepseek-chat`，SSE 流式生成），开箱即用。

- **为什么 Key 在前端？** 本站点是纯静态应用（零后端、零构建，直接由 GitHub Pages 提供），而 DeepSeek 官方接口支持浏览器跨域直连（CORS），因此要让“默认在线大模型”在公网开箱即用，Key 必须随站点提供（`assets/js/secrets.js` 内置演示 Key）。
- **⚠️ 安全说明（演示用途）**：API Key 写死在公开前端，**任何人都可查看并使用**。若该 Key 仍有效，请尽快到 https://platform.deepseek.com 重置。正式环境请勿将真实 Key 提交到前端，请改用：① 自建后端代理转发（Key 不落地前端）；或 ② GitHub 仓库 Secret + Actions 注入（Key 不进代码与 git 历史）。
- **离线兜底**：当在线调用失败（如网络异常、Key 失效、跨域被拦截）时，智能体会**自动回退**到内置离线模板引擎生成，保证演示始终可交互。你也可以在 **⚙ 智能体** 中手动切回离线模式。
- 点击右上角 **⚙ 智能体** 可查看 / 修改 Base URL、模型名，或粘贴自己的 Key 覆盖默认；遇到网络问题可点「🧪 测试当前连接」做中文诊断。

## 实现思路

### 整体架构

纯静态单页应用（SPA），采用经典 `<script>` 顺序加载（兼容 `file://` 与 GitHub Pages），所有模块挂载到全局 `window.App` 命名空间，无打包、无框架、无后端。

| 文件 | 职责 |
|------|------|
| `secrets.js` | 内置演示用 DeepSeek API Key（随站点公开提供，开箱即用） |
| `templates.js` | 11 个离线模板生成器 + 通用主题基座（CSS 变量 `--accent` + dark/light 双主题） |
| `auth.js` | 本地账号系统：注册 / 登录 / 记住我 / 找回密码 / 会话（密码 SHA-256 哈希） |
| `store.js` | localStorage 持久化，**按登录账号隔离**存储键 |
| `share.js` | 分享快照：把单文件 HTML 编码进 URL hash（base64），零服务器即可运行 |
| `llm.js` | OpenAI 兼容接口的 SSE 流式客户端，区分网络错误 / HTTP 错误 / 非流式降级 |
| `generator.js` | 智能体引擎：意图识别 + 离线模板生成 + 真实 LLM 路由 + 流式输出 + 失败回退 |
| `app.js` | 控制器：UI 绑定、登录门控、对话、预览、版本管理、设置、连接测试 |

**数据流（一句话）**：用户输入 → `generator.run()` 决策离线/在线 → 产出完整 HTML 字符串 → `app.js` 流式渲染进 iframe 预览 → 成功后存为版本并持久化到 localStorage。

### 智能体生成流程

1. 用户在中间栏输入需求 → 点击发送。
2. `generator.run()` 先触发四步状态卡片：`需求分析 → 方案规划 → 代码生成 → 渲染预览`，带流式打字机效果。
3. 模式决策（`settings.mode` + 是否含 Key）：
   - **离线引擎**：`classify()` 用正则做意图识别（待办/计算器/计数器/番茄钟/落地页/仪表盘/笔记/问答/游戏/天气 → 否则 `generic`），调用对应模板生成完整 HTML；若已存在上一版代码且命中编辑类关键词（改/换/颜色/主题/深色…），走 `incrementalEdit()` 做增量修改而非重生成。
   - **在线 LLM**：拼接系统提示（要求单文件、内联、真实可交互、CSS 变量主题、响应式），带上上一版 `history_code` 作上下文 → SSE 流式生成；失败时**优雅回退**到离线引擎并标注原因。
4. 流式呈现：在线是真实逐 token；离线是模拟打字机。
5. 渲染：代码写入 iframe 的 `srcdoc`（带 `sandbox` 限制），实时预览。
6. 版本与迭代：每次成功生成存为版本（`versions[]`），可 V1/V2… 切换；再次生成把当前版本作上下文，实现多轮增量编辑。

### 关键设计取舍

- **Key 放在前端**：纯静态 + CORS 直连，要让公网开箱即用的在线大模型只能如此；代价是 Key 公开（仅适合演示，正式环境改后端代理）。
- **localStorage 按账号隔离**：存储键 `atoms_demo_state_v2_<用户名>`，未登录落在 `guest`；多人同机互不干扰，但换浏览器/设备不共享。
- **分享零服务器**：应用代码 base64 进 URL `#app=...`，对方打开即运行；代价是大型应用 URL 较长（hash 有长度上限）。
- **离线兜底**：无论在线调用因何失败，都自动降级到内置离线引擎，保证演示**始终可交互**。

### 已知限制与风险

- ⚠️ **DeepSeek Key 公开在前端**（`secrets.js`），任何人都可扒出使用；若该 Key 仍有效，建议尽快重置。
- 离线引擎依赖正则意图识别，意图覆盖外的需求会退化到 `generic` 模板，质量有限。
- localStorage 约 5MB 配额，版本（每版是完整 HTML）积累多了可能写不进去（代码有 try/catch，不会崩，但最新版可能未存上）。
- 分享 URL 对大型应用会很长，部分浏览器/聊天软件对 URL 长度有限制。
- 在线调用依赖浏览器到 `api.deepseek.com` 网络可达；国内可能被网络/防火墙/广告拦截扩展拦截（已加诊断与排查文案）。
- 本地账号无服务端，换设备 / 清缓存不同步，仅作“需登录才能用”的演示门槛。

## 使用说明

### 给最终用户

1. 打开 https://cffypy.github.io/atoms-demo/ → 登录 / 注册（默认勾选“记住我”，下次自动登录）。
2. 在中间栏描述需求，例如：“生成一个待办清单网页，支持添加、完成和删除”。
3. 观察四步状态卡片 + 流式生成，右侧 iframe 实时预览。
4. 多轮修改：“主题色换成红色”“改成浅色模式”“把标题改成我的待办”。
5. 切到「代码」Tab 可直接手改源码 → 「保存并刷新」预览；「复制」「下载 .html」可导出。
6. 切到「分享」生成一条链接，发给别人打开即运行（无需服务器）。
7. 设置（⚙ 智能体）：切换在线/离线、粘贴自己的任意 OpenAI 兼容 Key 或 API 中转地址、点「测试当前连接」排查网络。

**内置 11 个离线模板**：待办清单 · 计算器 · 计数器 · 番茄钟 · 落地页 · 数据仪表盘 · 笔记(Markdown) · 问答测验 · 猜数字游戏 · 天气 · 通用应用。

### 给二次开发者

- 纯前端、**零构建**：直接双击 `index.html`，或 `python3 -m http.server 8000`。
- 加模板：在 `templates.js` 新增生成函数（复用 `theme()` 基座与 `SAFE_STORE` 安全存储），再到 `generator.js` 的 `RULES` 加一条正则意图即可被识别。
- 换模型：设置面板里填任意 OpenAI 兼容的 `baseUrl / apiKey / model`（如 GPT、Claude 中转、本地 Ollama）。
- 隐藏 Key（上线必做）：把 `llm.js` 里的 `fetch` 目标改为你自己的后端代理（Cloudflare Worker / Vercel Function），由代理持有 Key 并转发。
- 部署：推 `main` 分支，仓库 Settings → Pages → Source 选 `Deploy from a branch → main / root`。

## 部署到 GitHub Pages（分支部署，零构建）

仓库根目录即为站点根，推送到 `main` 分支后，在仓库 **Settings → Pages → Source** 选择 `Deploy from a branch` → `main` / `root` 即完成部署（本仓库已配置好）：

```bash
git push origin main
# Pages 设置：Source = Deploy from a branch → main / root → Save
```

本地调试：直接双击 `index.html`，或 `python3 -m http.server 8000`。

## 扩展路线

- **短期（体验 & 稳定性）**：更丰富的 `generic` 兜底模板 + 生成后处理；项目“导出 / 导入 JSON 备份”防数据丢失；分享长代码改用更紧凑编码或短链；加最简后端代理隐藏 Key。
- **中期（能力升级）**：多文件 / 多页面项目；组件化模板 + 用户自定义组件库；对话式调试（self-correction）；外部能力（上传 / 调用 API，需代理）；账号上云（Supabase / Firebase）实现跨设备同步。
- **长期（产品化）**：团队协作、项目分享社区、模板市场；接入更强 / 多模态模型；一键把生成的应用部署到静态托管；商业变现（订阅 / 企业私有化）。
